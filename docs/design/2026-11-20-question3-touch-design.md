# 题三：官方场景中的玩具触碰

沿用题一、二的提交目录。每个测例使用官方 Isaac Sim 4.5 场景和 ROS 2 Humble，单独重置到该行输入的底盘、目标玩具和初始关节状态。只在运行中的场景添加桥接、接触报告与演示相机，不保存到官方 USD，也不改模型几何。根据官方运动链、场景目标和关节限位规划接近，通过 ROS 2 Bridge 执行。

仅当 PhysX 报告目标玩具与夹爪的接触时捕获实际关节和场景变换，输出 `final_joint_state`、`objects_link_in_base_footprint`、`scene_object_in_objects_link`。三例按输入顺序完成后整体写入 JSONL，失败不拿示例补齐。保存完整运行日志和不超过 30,000,000 字节的演示视频；记录可复现命令与实测限制。
