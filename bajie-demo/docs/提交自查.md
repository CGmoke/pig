## 发布前检查

- [ ] `README.md` 填好报名信息、功能亮点、依赖获取方式与版本、三题执行目录和启动命令，写明实际视频文件名。
- [ ] 三题都有完整可运行源码；在不依赖外层开发工作区的环境里按 README 复跑过。
- [ ] 三个正式输入对应 **1 / 1 / 3** 条作答，输出 `id` 与输入一致；关节状态完整，位姿单位和四元数顺序符合题面。
- [ ] 题三每例保存实际触碰的证据，并报告玩具在 `objects_link` 中的位姿；按主办方确认的格式交付。
- [ ] `assets/` 收齐三题完整 `.log`；`video/` 题一、题三视频齐全，单个文件不超过 30,000,000 字节。
- [ ] 仅提交报名姓名目录：排除构建产物、缓存、外部依赖副本、令牌及无权公开的材料。
- [ ] 将独立 AtomGit 作品仓库登记到题面指定的飞书表单，并确认评审可以访问。
